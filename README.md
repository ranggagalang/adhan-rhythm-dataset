# Adhan Rhythm Dataset

This dataset contains adhan audio recordings collected for adhan rhythm classification research. The recordings are categorized into five commonly used adhan maqam classes and were prepared for machine learning and deep learning experiments.

## Classes

* Ajam
* Bayati
* Hijaz
* Nahawand
* Rast

## Dataset Description

The dataset consists of audio segments extracted from the **"Hayya 'alaṣ-Ṣalāh"** phrase of the adhan. This phrase was selected because it contains distinctive melodic characteristics that are suitable for analyzing and classifying adhan rhythms (maqamat).

Each audio sample represents a single rhythm class and has been manually organized into its corresponding category.

## Dataset Statistics

* Original samples: 250
* Number of classes: 5
* Samples per class: 50
* Audio format: WAV
